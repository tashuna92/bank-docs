## **Настройка аккаунта**

### Для настройки аккаунта выполните следующие действия:

| Действие  |  Скриншот экрана приложения |
| -------  | ------- |
| Введите ваш адрес электронной почты | <img src="account-email.png" alt="Экран ввода электронной почты" width="200"> |
| Выберите тип учетной записи из выпадающего списка | <img src="account-type-options.png" alt="Экран выбора типа учетной записи" width="200"> |
| Укажите ваш адрес регистрации | <img src="account-set-up-address.png" alt="Экран ввода адреса регистрации" width="200"> |
| Укажите ваши ФИО и дату рождения и нажмите **Далее** | <img src="personal-data" alt="Экран ввода личных данных" width="200"> |
